# 数据口径

样品编号标识物理样品，replicate 是独立复测编号。value 为统一浓度单位；status=below_limit 时只知低于 limit，value=null；缺记录不代表零。laboratory、lot 是测量环境而非独立样品。old 只是沿用方法，不是真值。limits 中 absolute、relative 表示可调整的容许误差系数，边界为 absolute + relative × 浓度绝对值。样品只在一种方法出现时仍保留在原始记录中。

## 方法比较口径

`method_exchange/comparison.py` 提供面向替换决策的比较，服务于“能不能换、在哪个量程能换”，而不是用相关系数代替互换性判断：

- **参考方法带误差**：参考读数与候选读数都被视为带测量误差的观测。斜率与截距采用 Deming 回归；误差方差比 lambda 由两方法各自同样品复测的合并方差（pooled within-sample variance）估计，缺少复测时 lambda 取 1 并显式标注为等方差假设，不把参考方法默认真值。
- **偏差随量程变化**：除 Deming 截距/斜率外，在低、中、高三个锚点给出模型偏差与相对偏差；另出 Bland-Altman 平均偏差与 mean ± 1.96 SD 一致性界限。一致性界限是描述区间，不是业务容许误差。
- **容许误差判定**：TEa(x) = absolute + relative × |x|，x 取参考方法可定量均值。页面可同时编辑绝对项与相对项，允许只设一项；两项均为 0 时只做描述，不输出合格/超限。
- **量程分箱与适用范围**：按观测量程等宽分为 6 箱，每箱少于 3 个配对标记“证据不足”，无样品箱标记“区间无证据”，均不输出互换结论；连续合格箱合并为适用范围，超限箱与证据不足箱分别列出。结论只覆盖观测量程，低于最低可定量读数和高于最高读数的区间保持空白，不向外推断。
- **复测、实验室与批次**：复测用于重复性方差，不重复计数样品；实验室与试剂批次分别汇总配对数、平均偏差、最大绝对偏差，只测过一种方法的分组显式标记为不可配对（如 late 批次只测过 new_b）。
- **检出限处理**：两方法均 below_limit 的样品只携带 limit，归入“两方法均低于检出限”，不按零值参与任何定量计算；一侧 below_limit、另一侧可定量时归入“仅一侧可定量”，不形成差值；同一方法部分复测 below_limit 时，差值只基于可定量复测并在样品明细标注。
- **可追溯**：每个分箱、分组和限制项都带支持它的样品编号，页面点击可定位到对应的样品级明细（复测值、检出限复测、实验室、批次、差值、容许误差与是否合格）。

## 数据版本

`fixtures/data.json` 是可直接导入的一份完整材料，`product.json` 保存页面默认范围。导入必须提交完整对象，不把省略字段解释为删除补丁；以规范化 JSON 的 SHA-256 标识内容，同内容多次导入复用版本。原始记录只追加版本，保存的分析材料始终指向原来版本。

页面中的范围与容许误差影响当前描述，不回写源数据。保存分析记录时，数据版本指纹、方法选择和当次容许误差约定（absolute、relative）一并冻结进记录；重新打开旧记录使用冻结的误差约定重新展示，不会被新数据自带的 limits 或后续导入覆盖。`null`、缺记录与实际零不能合并；数据格式问题应在导入时明确报错，而不是生成看似成功的空结果。涉及单位、时间或关系的解释以本文件为准，统计方法和业务决策没有预设结果。

## 目录

`method_exchange/domain.py` 提供现行领域校验和描述入口，`comparison.py` 实现 Deming 回归、Bland-Altman、量程分箱判定、分组与检出限口径，`validation.py` 处理基础引用与数值校验，`service.py` 连接领域操作和材料存档，`storage.py` 负责内容寻址数据与历史记录，`server.py` 提供本地接口。`web/app.js` 使用接口构建交互页面，不自行推导独立口径。
