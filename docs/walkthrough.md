# 短时复核路径

环境准备和镜像构建在操作前完成。服务的健康入口是 `/health`；服务启动即继续，不固定等待。正常本地启动在数秒内完成。若90秒内没有就绪，应停止操作并保留错误，不把等待算作成功运行。

从首页选择沿用方法与候选方法，在左侧“业务容许误差”中填写绝对容许误差和相对容许误差（可只填一项），点击“应用选择与误差约定”。页面给出：Deming 斜率/截距与低中高锚点偏差、Bland-Altman 偏差分布、偏差随量程变化图（绿色带为当前容许误差范围，红点为超限配对）、6 个量程箱的判定表、适用范围与超限/证据不足区间、实验室与试剂批次差异、检出限与单方法限制。

点击任意分箱、分组或限制项，下方“记录与依据”展示支持该结论的样品级明细；也可在样品配对明细中点击单行核对复测值与检出限复测。使用“查看原始记录”核对字段。输入会议名称并保存，保存内容冻结数据版本、方法选择和当次误差约定；然后改变所选范围或误差约定，点击左侧刚保存的记录，核对先前材料（包括误差输入框的值）仍按冻结时还原，最后导出当前记录，导出文件内含分箱结论与误差约定。整段交互通常需要 45 至 90 秒，不依赖远程请求。

量程解读要求：观测量程之外没有证据，页面保持空白结论，不向外推断；标为“证据不足”的箱子配对少于 3 个，不能作为合格或超限依据；两方法均低于检出限的样品不按零值处理，量程下端的互换性需要补测。只测过一种方法的批次只能从原始记录核对，不参与配对判定。

`fixtures/data.json` 可用于重新导入核对。页面说明的是观测和适用范围；不要为了演示修改数据以制造某种优胜、显著性或异常结论。新增加的分析也应从真实可用证据解释结果，不要求出现某个指定方向。
